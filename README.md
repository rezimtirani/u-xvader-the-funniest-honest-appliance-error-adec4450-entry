One single line: the funniest honest error message an appliance could show. A washing machine refuses to spin — its load is unbalanced, one sock is missing, and the drum wants someone in the house to admit where it went.

> ERROR E12: Unbalanced load. One sock is missing and the drum refuses to spin until someone in this house admits where it went.

## How it works

`main.py` (Python 3 standard library only) writes the error line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
